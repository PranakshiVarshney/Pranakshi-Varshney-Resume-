## Design

- Palette: deep forest green with antique gold and ivory text
- Fonts: Cormorant Garamond (headings), Inter (text), IBM Plex Mono (labels)
- Dark theme by design, responsive from phones to wide screens
- A gold light trail follows the mouse on devices that have one
- Use the "Save as PDF" button for a clean print version

Built with plain HTML, CSS and JavaScript. No frameworks.
